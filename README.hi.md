# Android Phone Debloater (हिन्दी)

यह रिपॉजिटरी AI एजेंटों (जैसे OpenCode और Claude) के लिए एक विशेष स्किल प्रदान करती है ताकि ADB (Android Debug Bridge) का उपयोग करके Android फोन और टैबलेट से ब्लोटवेयर (bloatware) को हटाया जा सके। यह अनावश्यक प्री-इंस्टॉल किए गए ऐप्स को हटाता है, जिसमें Google ऐप्स और ब्रांड-विशिष्ट ऐप्स शामिल हैं, यह सुनिश्चित करते हुए कि डिवाइस कार्यात्मक बना रहे।

## 🤖 एजेंट के लिए निर्देश

जब इस रिपॉजिटरी को एक स्किल के रूप में लोड किया जाता है, तो एजेंट को चाहिए:
1. **ADB सत्यापित करें**: जांचें कि वातावरण में `adb` उपलब्ध है या नहीं।
2. **डिवाइस कनेक्ट करें**: दिए गए डिवाइस आईडी या आईपी के साथ `./tools/debloat.sh` का उपयोग करें।
3. **सुरक्षा जांच**: उपयोगकर्ता को सूचित करें कि Google Play Store और सक्रिय लॉन्चर सुरक्षित हैं और उन्हें हटाया नहीं जाएगा।
4. **निष्पादन**: डिबलोट स्क्रिप्ट चलाएं और परिणाम की रिपोर्ट करें।

## 🚀 विशेषताएं

- **व्यापक निष्कासन**: सिस्टम के महत्वपूर्ण घटकों को छोड़कर सभी इंस्टॉल किए गए पैकेजों को लक्षित करता है।
- **सुरक्षा पहले**: 
  - **Google Play Store की सुरक्षा**: सुनिश्चित करता है कि आप अभी भी ऐप्स इंस्टॉल और अपडेट कर सकें।
  - **डिफ़ॉल्ट लॉन्चर की सुरक्षा**: डिवाइस को ब्रिक (brick) होने से बचाने के लिए सक्रिय लॉन्चर का गतिशील रूप से पता लगाता है और उसे सुरक्षित करता है।
- **बैकअप तंत्र**: यदि कोई पैकेज पूरी तरह से अनइंस्टॉल नहीं किया जा सकता है, तो टूल उसे अक्षम (disable) करने का प्रयास करता है।
- **ADB एकीकरण**: USB या वाई-फाई के माध्यम से काम करता है।

## 🛠️ पूर्व-आवश्यकताएं

1. **ADB इंस्टॉल**: सुनिश्चित करें कि आपके कंप्यूटर पर `adb` इंस्टॉल है।
2. **USB डिबगिंग सक्षम**: 
   - `सेटिंग्स` $\rightarrow$ `फोन के बारे में` $\rightarrow$ `बिल्ड नंबर` पर 7 बार टैप करें।
   - `सेटिंग्स` $\rightarrow$ `सिस्टम` $\rightarrow$ `डेवलपर विकल्प` $\rightarrow$ `USB डिबगिंग` सक्षम करें।
3. **डिवाइस कनेक्ट**: अपने फोन को USB या वाई-फाई के माध्यम से अपने कंप्यूटर से कनेक्ट करें।

## 📖 उपयोग

### AI एजेंटों के लिए
एजेंट बस इसे चला सकता है:
```bash
chmod +x tools/debloat.sh
./tools/debloat.sh [device_id/ip]
```

### मैनुअल उपयोग
यदि आप इसे मैन्युअल रूप से चला रहे हैं:
```bash
chmod +x tools/debloat.sh
./tools/debloat.sh <आपका_डिवाइस_आईडी_या_आईपी>
```

### ऐप्स को रिस्टोर करना
यदि आपने गलती से कुछ महत्वपूर्ण हटा दिया है, तो आप निम्नलिखित ADB कमांड का उपयोग करके उसे पुन: इंस्टॉल कर सकते हैं:
```bash
adb shell cmd package install-existing <पैकेज_का_नाम>
```

## 📂 प्रोजेक्ट संरचना

- `tools/`: डिबलोट और रिस्टोर करने के लिए मुख्य स्क्रिप्ट शामिल हैं।
  - `debloat.sh`: ब्लोटवेयर हटाने के लिए मुख्य स्क्रिप्ट।
  - `restore.sh`: रिस्टोरेशन गाइड के लिए यूटिलिटी स्क्रिप्ट।
- `AGENTS.md`: इस रिपॉजिटरी में काम करने वाले AI एजेंटों के लिए विशिष्ट मार्गदर्शन।
